# Mahata Static Website

Website satu halaman berbasis HTML, CSS, dan JavaScript murni. Tidak memerlukan proses build atau instalasi paket.

## Menjalankan

Buka `index.html` langsung di browser, atau aktifkan GitHub Pages dari branch utama dengan root folder sebagai sumber.

## Struktur

- `index.html` — seluruh konten halaman
- `style.css` — tampilan dan responsivitas
- `script.js` — menu mobile, FAQ, animasi, dan navigasi aktif
- `privacy-policy.html` — halaman Kebijakan Privasi
- `assets/` — logo dan foto proyek
